# 手动外出与两阶段自动归巢 Demo

从桌面终端启动：

```bash
cd /media/lg/lg-512/new_workspace/Bird_Nav_ws/Bee-Nav
bash visual_simulator_docker/run_interactive_homing_demo.sh
```

使用既有磁盘 Docker / Isaac Sim 4.2 环境。程序在后台打开图形窗口；可关闭窗口或点击
Exit 退出。一次只能运行一个 demo，避免争用 GPU。每次启动独立保存日志，不覆盖实验。

## 操作

先点击视口使其获得键盘焦点，按 T 起飞到 40 m，等待状态变成 MANUAL，再手动外出。

| 按键 | 功能 |
|---|---|
| T | 从地面起飞 |
| W / S | 沿机头方向前进 / 后退 |
| A / D | 相对机头方向左移 / 右移 |
| Q / E | 左转 / 右转 |
| H | 结束手动外出，开始自动两阶段归巢 |
| Space | 暂停 / 恢复 |
| V | 重新显示俯视与相机子窗口（主视图固定第三人称） |
| R | 结束当前演示，回到起点开始新飞行 |

窗口按钮提供起飞、自动归巢、暂停、新飞行、恢复子窗口和退出。
`Simulation speed` 调整手动和路径积分阶段的模拟推进速度（1–30 倍），
方便进行公里尺度外出；靠近起点时建议调低，便于操作。
`PI sigma for NEXT flight` 调整下一次飞行的噪声系数（0–2 m/√m），修改后按 R 应用。
当前生效的 sigma 在状态栏独立显示，避免在途中悄悄改变噪声条件。

## 统一归巢结果窗口

两个阶段归巢并降落完成后，后台生成结果，在同一个 `Two-stage homing results` 窗口
一次显示三幅图。外出结束、PI 结束及视觉归巢过程中均不弹出结果窗口。

- 左上：外出真实轨迹、地磁辅助里程计估计和仅靠陀螺仪的漂移估计。
- 左下：第一阶段归巢全程对比（原 Stage 1 的右上子图），含两种归巢预测、实际 PI 归巢和 15 m 圈；坐标范围自动覆盖整条轨迹。
- 右侧：第二阶段完整视觉归巢轨迹，含实际动作位置、行进箭头、步数、起终点、降落点及 2 m 圈。

地磁航向噪声为零；无地磁预测以 0.63°/√s 累积航向漂移。预测采用固定 0.5 s / 2 m
步长，实际 PI 轨迹使用真实记录，两者均按内部估计到家，不使用真值修正归巢方向。
当前保留原 Stage 1 的左上、右上子图，不再绘制近家放大图或 50 次回放散点图。

关闭结果后可按 V 重新显示；按 R 开始新飞行时隐藏旧图。历史已保存的图和数据继续保留。

## 两阶段逻辑

1. **手动外出**：无噪声绝对航向；按原 PI 模型积累名义位移，真实位移叠加
   标准差 `sigma * sqrt(step_length)` 的高斯距离误差。默认 sigma=0.1。
2. **路径积分归巢**：按内部积分位置指向估计的家，累计返程误差，最后一个不足整步的
   位移正常执行。内部积分归零后进入视觉阶段。**不使用真实 15 m 距离提前切换。**
3. **视觉归巢**：使用 Stage23 的 epoch484 TorchScript，40 m 高度、30° 下视相机、
   1024² 渲染输入，模型内执行 384² 预处理与圆形掩膜。步长沿用原控制器，最大 2.5 m。
   真实距离 ≤2 m 时成功停止，最多 50 步；这是模拟器评分条件，不是实机到家识别器。

界面同时显示真实距家距离、内部估计距家距离、外出里程、当前阶段、视觉步数和
PI 接管时的真实距离。15 m 是已研究的视觉接管范围，不是位置传感器输入。
如果 PI 实际终点已在 2 m 内，会按已有规则直接成功，不强行多走视觉动作。
如果接管落在 15 m 外，仍如实尝试视觉归巢；超过场景支持区域时失败并说明原因。
不会传送回家或使用真值方向替代网络预测。

视觉归巢以 SUCCESS 或 FAILED 正常结束后，自动进入 LANDING，在实际终点垂直
缓慢下降到地面，完成后显示 LANDED。下降过程约 20 秒，支持空格暂停，保持水平坐标
和归巢误差；速度滑块不加速下降。成功与失败结果在降落后继续分别显示。
ERROR 属于取图/推理异常，停留现场供排查，不作为一次正常归巢结束处理。

降落后标出绿色起点、粉色降落点及连接线，显示 START 到 LAND 的水平距离。
总览右下角的局部测距放大框可以辨认公里尺度飞行后不足数米的误差。
测距使用模拟器真实坐标，单位为米，独立保存为 `episode_XXX_landing.json`。
这是现有运动学演示的垂直下降，仍使用平坦地面假设。

## 轨迹记录与导出

统一窗口右侧只使用第二阶段的已完成动作位置：第 0 点是 PI → 视觉接管位置，
之后每一点对应一个实际完成的网络动作；垂直降落不计入视觉导航轨迹。
接管时已经位于 2 m 内时，保留单一起点并标明未执行视觉移动。

最终图片和完整记录为 `episode_XXX_homing_results.png/.json`；PI 原始记录为
`episode_XXX_pi_trace.csv`，视觉阶段动作位置仍保存为
`episode_XXX_visual_trajectory.csv/.json`。导出在后台进行，完成后只自动弹出一次。

## 场景与限制

使用此前房屋、树木、水池场景和 7 km 草地。飞行代理使用 Quaternius 的 CC0 鹰模型，
保留其原有网格和骨骼，通过导入的 Idle/Flying 姿态进行振翅展示。
素材来源、许可与文件校验见 `assets/birds/quaternius_eagle/README.md`。
飞行是运动学仿真，无空气动力学、碰撞或真实飞控。手动水平边界为 ±3200 m，
视觉阶段边界为 ±190 m；碰到边界会暂停或报告失败。

主视图固定第三人称；另有实时俯视总览和下视 RGB 两个子窗口。总览附已飞路径、
当前位置、机头朝向箭头及起点 15 m 圈。总览保持北向上，黄色箭头表示机头，
0° 朝东、90° 朝北，侧移时箭头仍表示机头而非速度方向。
相机窗口显示实际传感器的 1024² 图像，窗口内下采样显示，
网络仍使用完整输入。主视图不会因为用户点击另一个窗口而切换相机。

取图使用平移到独立区域的同一场景副本，不包含演示用鸟模型、圆圈或轨迹。
主场景的鸟全程可见，不再为了网络取图隐藏模型。副本保留原始资产、比例和纹理，
并停用重复光源；与原场景的图像及模型输出差异通过真实渲染验收记录。
新帧、相机姿态与图像稳定性检查在主循环中逐帧执行，不再使用阻塞式取图循环。
子窗口与主界面同步更新，神经网络使用姿态匹配且通过稳定性检查的新观测。

PI → 视觉归巢时显示 3 秒阶段切换提示和实际接管距离。每次神经网络预测后，
用至少 1.2 秒、至少 36 次显示更新的连续位置插值与最短角度转向展示动作，移动结束才计为已完成一步，
并检查成功或失败；网络选定的动作端点与原控制规则不变。取图期间鸟保持可见并悬停，
界面显示正在获取稳定图像。暂停会冻结当前动作，重新开始会取消尚未完成的动作。
起飞前或手动阶段的速度滑块不加速视觉动作，以保留可观察的归巢过程。

## 文件和验收

每次运行的目录：`visual_simulator_docker/CodeInsectInspired/runs/interactive_demo/<时间戳>/`。

- `protocol.json`：模型、相机、控制器和噪声设置。
- `events.jsonl`：阶段变化、飞行轨迹、网络预测、动作与暂停/重置事件。
- `status.json`：最新状态。
- `episode_*_visual_*.png`：网络实际看到的图像。
- `episode_*_landing.json`：起点、实际降落点、水平误差及归巢成功/失败结果。
- `episode_*_homing_results.png/.json`：三图合一的最终结果和完整轨迹记录。
- `episode_*_pi_trace.csv`：外出真实/估计位置与实际 PI 归巢记录。
- `episode_*_visual_trajectory.csv/.json`：第二阶段实际动作位置数据。
