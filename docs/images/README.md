导航使用第 484 轮参考模型、40 m 高度、30° 方形下视视场。
演示的路径积分距离噪声系数为 0.1 m/√m，地磁航向无噪声，视觉到达半径为 2 m。
外出通过演示原有键盘控制完成，归巢由路径积分控制器和视觉网络执行。

外出航程约 1.98 km，视觉接管距离为 9.16 m，完成 11 步视觉导航后在距起点约 1.81 m 处降落。
这是一条单次演示轨迹；批量实验成功率见仓库首页的参考结果表。
