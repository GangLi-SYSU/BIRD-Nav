# 第七阶段补充：过拟合原因与下视输入适配

日期：2026-10-27。本报告分析已冻结的 `stage07_training/attention_8h_01`，不修改原始图像、分组、网络、配置或训练权重；本轮没有重新训练模型。

## 结论与证据边界

**建议优先适配方形输入及对应全连接层，再用相同数据做对照。** 192×1800 是原全景网络的输入，直接用于方形下视图会显著改变几何比例，原卷积链的末端空间结构也不适合直接视为二维地面表征。

目前证据支持多因素共同作用：输入/特征几何失配、窄视场下地物组合不足、有限位置和离散航向缺乏连续变化约束，以及重复训练产生记忆。尚未训练方形输入的对照模型，因此不能量化各因素贡献，也不能承诺只改 resize 就能解决全部问题。

原模型已能拟合训练图：训练/验证/测试平均方向误差分别为 7.01° / 91.71° / 91.68°。这不支持优先扩大网络容量；应先检验模型是否保留了适合当前相机的空间结构。

## 一、确认沿用了原论文的全景输入

[论文 Methods](https://www.nature.com/articles/s41586-026-10461-3) 的 Image processing / Neural networks 明确说明：环形全向图展开为全景图后，网络输入为 `3×192×1800`。原代码 [simple_network.py](../visual_simulator_docker/CodeInsectInspired/simple_network.py) 第 114 行同样执行：

```python
F.interpolate(x, size=(192, 1800), mode='bilinear', align_corners=False)
```

这里顺序是 **高×宽**。本次原始相机仍为 1024×1024、30°×30°，进入网络后被变为高 192、宽 1800：

- 横向缩放为 1.758 倍，纵向缩放为 0.1875 倍，二者相差 **9.375 倍**。
- 圆形地物会变成很扁的椭圆；不同方向的平移、旋转不再具有相同的图像尺度。
- 把相机换成下视，已经改变了视觉任务；“保留原模型基线”不能代替验证模型与新投影的适配。

这不改变相机真实 FOV，也没有把下视图变成全景图。[实际 resize 对比图](../visual_simulator_docker/CodeInsectInspired/runs/stage06_data/position_groups_01/inspection/network_resize.png)可直接看到形变。方形输入不要求保留原始 1024 分辨率，等比例缩小即可。

## 二、问题还涉及卷积末端，不能只改一行 resize

已在现有 PyTorch 2.4 容器中执行 CPU 前向尺寸探测，未训练或保存候选网络。沿用相同 Inception、attention、卷积层和 tanh，得到：

| 输入高×宽 | 末端特征图 H×W | 展平长度 | 适配 fc 后总参数 |
| --- | --- | ---: | ---: |
| 192×1800，现有基线 | 1×52 | 208 | 10,820 |
| 192×192 | 1×1 | 4 | 7,556 |
| 256×256 | 3×3 | 36 | 8,068 |
| **384×384，首选对照** | **7×7** | **196** | **10,628** |
| 512×512 | 11×11 | 484 | 15,236 |

末端通道数均为 4；参数变化只来自尺寸匹配的第一层 fc。现有 `1×52` 特征格已经没有多个纵向格点，和二维地面的位置关系存在结构失配。**这不表示纵向信息必然完全丢失**，因为它仍可能编码在通道和感受野内；这里指出的是空间表征偏置，贡献大小需要训练对照验证。

384×384 的末端为 `4×7×7`，fc 输入从 208 调整为 196，参数量接近原模型，适合控制容量差异。192×192 虽保持比例，却会让本卷积链只剩 `1×1`，不作为首选。512×512 保留更多像素，但 fc 参数也明显增加，解释对照时需考虑该变化。

对应修改必须包含输入尺寸、尺寸断言、`flatten(1)` 和 `Linear(196,16)`；训练、验证、在线推理、重载、ONNX 统一使用同一模型配置。原来的硬编码 `view(-1,208)` 和 fc 不能保留。应新增下视变体、从头初始化，在新目录训练，保留原基线与历史指纹。

## 三、路标排布可能有影响，但无法单独解释失败

10 m AGL、30°视场在平地上只覆盖约 **5.359×5.359 m**。400×400 m 大场景中的物体总数，不等于单帧可见地物数量。当前 192 个物体中，96 个在中央 72×72 m 内，另 96 个在外围；颜色和形状组合只有 12 种，会重复出现。

采用“路标 XY 包围圆与地面视场正方形相交”作保守筛查：

| 路标候选数量 | 图像数 |
| ---: | ---: |
| 0 | 368（31.3%） |
| 1 | 576（49.0%） |
| 2 | 224（19.0%） |
| 3 | 8（0.7%） |

这是几何候选数，**不是实际可见物体分割**；包围圆、地面最大视场会高估可见性，未分类阴影。0 候选意味着视场没有接触任何物体的 XY 包围范围，图像仍有地面纹理。高处物体对应的实际视场更小。

单个圆柱、圆锥或球体的俯视外观具有旋转对称性，相同颜色/形状又会重复；仅看见一个物体，不保证具有足够的定位和定向信息，需要纹理或多个物体的相对关系。这里“增加物体”与“增加可辨识信息”并不等价。

测试集进一步分组：0 路标候选的 36 图，平均方向误差 **85.76°**；有候选的 28 图为 **99.29°**。两组都差，不能得出“只要加密路标就能解决”的结论。只有 8 个独立测试位置，这项分组为描述性诊断，不能作为路标可见性对性能的因果检验。

当前地面纹理覆盖 400 m，分辨率为 8192；约 4.88 cm/纹素，一次地面视场宽度对应约 110 个纹素。1024 像素的原始照片并不代表有 1024 个独立纹理样本。该数值提示检查实际图像信息量，但不能单凭它判定纹理分辨率不足。

## 四、数据问题是空间/航向泛化，不只是“图像数量少”

训练集 1064 张实际上来自 **133 个位置，每位置 8 个航向**。没有连续地面覆盖或连续航向变化的保证，不能把八张图当作八个独立位置。

| 未见集合 | 最近训练位置距离：均值 / 最大 | 最近位置内的最近航向差：均值 / 最大 |
| --- | --- | --- |
| 验证 | 0.656 / 1.041 m | 10.97° / 16.21° |
| 测试 | 1.061 / 2.013 m | 12.62° / 18.78° |

测试位置并非全部远离训练区域。即使附近有训练图，1 m 左右的位移和十几度的航向变化仍可能让地物在窄视场内大幅移动、进出边界；现有网络没有学会可靠处理这些局部变化。该结果同时指向输入几何与数据变换约束，不能仅归为学习区域太小。

[论文 Methods](https://www.nature.com/articles/s41586-026-10461-3) 使用随机航向增强；原代码在全景上用横向循环移位，并同步转动标签。本次下视数据关闭了全景 wrap，采用八次真实拍摄，避免把错误的全景变换用于下视，但也没有连续航向增强。两者的学习约束不等价。

下视图的真实偏航变化对应二维图像旋转与视场边角变化；未来增强需同步变换标签，并处理有效画幅，不能直接恢复横向 wrap，也不能让任意角度旋转产生的黑边成为定位线索。首轮方形输入对照仍保留八航向与关闭增强，以免同时改变多个变量。

## 五、较低优先级的解释与已检查项目

- **训练轮数与正则化：** 早期验证 MSE 约 12.41–12.43 m²，接近恒零参考 12.35，后期升至 29.28；早停可能减少过拟合，却可能只留下接近零的输出，不能据此认为已学会方向。本次八航向使原 150 epochs 对应更多更新及重复呈现，不能把相同轮数视为相同更新预算。
- **优化失败或容量不足：** 训练 MSE 0.157、方向误差 7.01°且全部 19,950 次更新有效，不支持优先靠更大网络或更多训练来解决。仍需对照验证容量与正则化的作用。
- **标签公式/重复帧：** 1176 张 PNG 哈希全部不同；按 `R(-yaw)·(-position)` 重算标签最大误差为 0，实测/计划位置最大差约 1.6e-14 m。结合已有相机标定与稳定取图检查，暂未发现这类错误证据，不能据此排除所有潜在实现问题。
- **全局固定角度符号错误：** 测试误差不是都偏同一个角度；有符号角误差的圆统计集中度约 0.080，方向分散。平均误差约 92°不能直接解释为“统一错转了 90°”。
- **测试集合与归纳边界：** 固定位置分组没有空间隔离带，本来相对有利于局部插值，仍表现较差；当前只有一个场景、一个训练种子、8 个测试位置，无法给出稳定的因素贡献排序或大范围导航结论。

## 建议的验证顺序

1. **先做输入适配对照。** 新增 384×384 下视变体；卷积主干、attention、激活、seed、原始图像、固定划分、八航向、优化器、batch 和正式轮数保持一致，仅适配输入与必要的 fc 维度。训练前先做前向和短训练检查；正式结果与当前基线并列报告。
2. **根据验证集诊断局部变化。** 检查最近训练图、航向差与错误样例；分别研究新增连续/更密航向，以及更密位置采样。新图按位置分组，不把同位置八航向拆开。
3. **独立改变场景信息。** 如仍失败，再对照多地物可见率、重复外观、纹理尺度与几何排布；用相同学习路线和起始协议，避免同时改场景、网络与视场。
4. **后续研究正则化与模型结构。** 在同一验证协议上评估，不用现有测试集调输入尺寸或挑选权重。当前测试结果已用于诊断，若要提出新的严格独立测试结论，需要另行预留未使用的位置/场景。

本轮推荐的是 **384×384 首个适配候选**，依据是几何保持与接近的参数量，不是已经验证它精度更高。尚未修改原模型；后续尺寸与实验设置应由用户确认。
