## 关于旧损失曲线

旧训练前20轮验证分量MSE均值约214.3 m²，21–50轮约246.6 m²，101–150轮约211.3 m²，201–227轮约245.0 m²；已有最佳验证值为第146轮的180.05 m²。误差确实偏高且有波动。

原133个训练位置中仅60个在20 m内、73个在20 m外；窄视场下目标区域采样较稀疏，是此次调整的直接依据。验证集只有6个独立位置，8航向视图互相关联；在线随机旋转和固定学习率也会使逐轮结果波动。先升后降或不平滑本身不能证明训练实现出错，也不能保证仅压缩轨迹就会解决全部问题。

新实验保留真实逐轮曲线，不改学习率、损失函数或验证规则来追求视觉平滑。由于目标向量随学习范围缩短，即使预测始终为零，绝对MSE也会随坐标尺度平方下降；不能仅凭新曲线更低宣称泛化改善，仍需检查向量误差和相同10／20 m、2 m成功半径下的导航结果。

沿用原分组后，6个验证位置均在约12 m半径内，15–20 m没有独立验证位置。这次保持分组以单独检查轨迹压缩的影响；20 m边界表现仍须由正式导航测试单独报告，不能从验证曲线直接推断。

## 启动与查看

从 `Bee-Nav/` 启动：

```bash
bash visual_simulator_docker/run_compact_spiral_on_disk.sh \
  --run-dir runs/stage23_compact_spiral_h40_fov30_01
```

状态：`pipeline_progress.json`；新旧轨迹对比：`analysis/compact_vs_previous.png`；实时损失和轨迹：`analysis/live_results.html`（30秒刷新），对应 `training_live.png`、`navigation_live.png`；采集预览：`training_camera_preview.png`；最终报告：`result_summary.md`。图像和训练产物在相应阶段开始后生成。

20 m测试起点位于采样中心范围边界，若预测把无人机带到20 m之外，则进入未沿轨迹采样的中心位置；这一限制需在最终结果中保留。全部运行产物保存在项目所在硬盘。
