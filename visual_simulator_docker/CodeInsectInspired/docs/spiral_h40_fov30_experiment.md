# 40 m／30°螺旋数据训练与归巢测试

## 实验设置

- 使用现有房屋、树木、水池场景，离地40 m，理想垂直下视相机，水平和垂直视场角均为30°，原始RGB为1024×1024。
- 重新渲染原始 `generate_bee_path(5,150,1.4)` 的147个位置，最大半径约44 m；每位置8个航向，共1176张新图。没有二维覆盖或近家额外采样，没有复用70°照片。
- 沿用seed10和按位置分组的原划分比例：133个训练位置／1064张图，6个验证位置／48张，8个保留测试位置／64张。同位置8个航向整体分组。
- 从头训练600轮；旧600轮模型和近家微调模型均不提供初始权重。网络仍为384×384、10628参数，训练随机旋转并同步变换向量标签，固定圆形掩膜半径190像素。
- AdamW、学习率0.0005、batch8、目标向量除以44；部署输出恢复米。600轮共79800次更新，保留最终权重，并按验证误差选取部署权重。保留测试图像不参与模型选择。
- 正式神经导航仅测试10 m和20 m，每半径16方位×4初始航向=64次，总计128次。最多50步，步长仍为 `min(0.1+0.4×预测距离/3,2.5)` m。
- 成功条件为每步端点真值**水平距离≤2 m**，不是归巢点进入图像。真值向量检查和部署一致性检查单独标记，不计入正式神经导航成功率。

## 执行顺序与记录

1. 冻结协议、螺旋轨迹、分组、场景和源文件哈希。
2. 用4台并行相机采集，逐帧检查实际位姿、30°光学参数、渲染设置和稳定性；按批原子提交，断点只恢复已核验样本。
3. 审计全部1176张图及其标签；不允许增加轨迹外位置或重新分组。
4. 独立执行2轮短训练检查；正式训练重新初始化，不复用检查权重。
5. 完成600轮，按验证集选定模型并核验TorchScript／ONNX导出一致性。
6. 执行几何、渲染真值向量和部署检查，再完成128次正式测试；输出两种初始距离的成功率、最终距离和轨迹。

## 解释结果时的限制

30°视场下有效圆形地面半径约10.6 m；10 m起点虽可看到归巢点，仍需导航至2 m范围内。窄视场会减少画面地标数量，螺旋数据只有147个位置，因此仍可能出现覆盖不足或歧义；本次不会通过额外采样改变该约束。

这是单场景、单训练种子的运动学测试，尚未验证真实飞行动力学或实机到家识别。与旧实验相比，相机视场、训练数据来源和成功阈值同时改变，不能把成功率差异全部归因于视场角。
