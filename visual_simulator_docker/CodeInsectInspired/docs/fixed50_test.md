# 15 m起点、固定50步的终点误差测试

上一组15 m实验在首次进入2 m范围时停止，结果为59/64成功。本实验沿用同样64个起始组合（16方位×4航向）、第484轮模型、40 m高度、30°视场角、圆形输入和原动态步长；唯一控制流程改动是**取消按归巢距离提前停止，固定执行50次网络决策**。

相机每步重新拍摄稳定帧并推理，进入2 m后仍继续执行原动作。不会加入悬停、真值方向修正或真值末步裁剪，也不会把提前结束的轨迹补齐为50步。旧实验的冻结源文件和结果保留，新运行器独立保存。

## 统计口径

- 主要结果为每条轨迹第50步端点到归巢点的真值水平距离，统计均值、中位数、P90、P95、最大值和均方根距离。
- 同时记录最终位置在0.5／1／2／3／5 m等范围内的数量。
- 分开报告途中曾进入2 m、最终仍在2 m内、曾进入但最终离开2 m的轨迹数。
- 保留最小端点距离、首次进入2 m的步数、最后10个端点的距离均值／最大值／波动，用于观察偏置或绕圈。
- 异常帧或无效预测按工程异常记录，未跑满50步的轨迹不混入第50步终点统计；完整报告要求64条全部完成50步。

## 运行与输出

从 `Bee-Nav/` 启动：

```bash
bash visual_simulator_docker/run_fixed50_on_disk.sh \
  --run-dir runs/stage25_fixed50_15m_01
```

运行目录为 `runs/stage25_fixed50_15m_01/`：`pipeline_progress.json` 显示进度；`analysis/live_results.html` 自动刷新图像；完成后生成 `formal/results.json`、`analysis/endpoint_distances.csv` 和 `result_summary.md`。

原15 m的渲染真值向量与模型部署检查已核验并复用；新的固定步数规则另做纯几何检查。不会重新训练、采集训练数据或更换部署权重。全部输出存放在项目所在硬盘。

当前使用运动学相机代理，第50步端点不等于实机悬停平衡点；本实验衡量连续网络控制50步后的误差与稳定性迹象。
