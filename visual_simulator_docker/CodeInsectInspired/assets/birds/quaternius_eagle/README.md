# Quaternius eagle display asset

Author: Quaternius. License: CC0 1.0 (see EZ-CC0-LICENSE.txt).
Original release: https://opengameart.org/content/animated-animales-low-poly
Archive mirror: https://hydecogames.com/art/packs/quaternius-animated-animals-vol2/

The imported FBX and authored rig replace the old procedural white bird.
Isaac asset conversion generated eagle.usd, props/ and animations/; all are local.
The converter retains static idle/flying poses in this asset. The display interpolates
these poses and applies a sinusoidal shoulder flap on the authored skeleton, with a brown/cream/gold palette and a normalized
scale. This is presentation animation, not aerodynamic simulation or new training data.
The display model is absent from the independent neural-camera scene.
Source/archive hashes and conversion details are recorded in PROVENANCE.json.
